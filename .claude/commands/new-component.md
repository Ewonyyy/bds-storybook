새 컴포넌트 작업을 시작한다: $ARGUMENTS

아직 프로젝트에 구체적인 컴포넌트 규칙(디자인 토큰, 폴더 구조 등)이 없으므로 아래 최소 절차를 따른다:

1. 요청받은 컴포넌트의 목적과 사용 위치를 먼저 확인한다.
2. 기존에 유사한 컴포넌트가 있는지 찾아보고, 있다면 재사용/확장을 우선 고려한다.
3. `component-builder` 에이전트에게 구현을 위임한다.
4. 여러 컴포넌트에 걸친 구조적 판단이 필요하면 `architect` 에이전트에게 검토를 요청한다.

디자인 시스템 규칙이 구체화되면 이 커맨드를 그에 맞게 업데이트할 것.
